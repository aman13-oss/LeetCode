# 4066. Maximum Equal Adjacent Pairs After at Most One Replacement

**Difficulty:** Medium

## Problem

You are given an integer array `nums`.

You may replace at most one element in the array with any integer.

An adjacent pair is considered equal if the two neighboring elements have the same value.

Return the maximum number of equal adjacent pairs that can be obtained after performing at most one replacement.
