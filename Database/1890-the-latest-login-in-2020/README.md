# 1890. The Latest Login in 2020

**Difficulty:** Easy

## Problem

Write a solution to report the latest login for all users in the year 2020.

If a user did not login in 2020, do not include them in the result.

Return the result table in any order.

## Example

### Input

**Logins**

| id | time |
|---:|:---|
| 1 | 2020-05-30 |
| 1 | 2020-06-01 |
| 2 | 2020-06-01 |
| 2 | 2021-01-01 |

### Output

| id | time |
|---:|:---|
| 1 | 2020-06-01 |
| 2 | 2020-06-01 |
