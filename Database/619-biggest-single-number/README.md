# 619. Biggest Single Number

**Difficulty:** Easy

## Problem

Table: `MyNumbers`

| Column Name | Type |
|---|---|
| num | int |

This table may contain duplicate numbers.

## Task

A **single number** is a number that appears only once in the table.

Write a solution to find the largest single number.

If there is no single number, return `null`.

## Example

### Input

| num |
|---:|
| 8 |
| 8 |
| 3 |
| 3 |
| 1 |
| 4 |
| 5 |
| 6 |

### Output

| num |
|---:|
| 6 |

### Explanation

The numbers that appear only once are `1, 4, 5, 6`.

The largest single number is `6`.
