# 4065. Rearrange Array by Removing Distinct Values

**Difficulty:** Easy

## Problem

You are given an integer array `nums`.

You may perform the following operation any number of times:

- Choose an element from the array whose value occurs exactly once.
- Remove that element from the array.

After performing the operations, rearrange the remaining elements in any order.

Return the maximum possible number of equal pairs that can be formed from the remaining elements.

## Example

**Input:**
```text
nums = [1,2,2,3,3,3]
