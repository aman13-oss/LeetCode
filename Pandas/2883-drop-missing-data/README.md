# 2883. Drop Missing Data

**Difficulty:** Easy

## Problem

Given a DataFrame `students`, remove all rows that contain a missing value in the `name` column.

Return the resulting DataFrame.

### Input

```text
+------------+-------+
| student_id | name  |
+------------+-------+
| 1          | Alice |
