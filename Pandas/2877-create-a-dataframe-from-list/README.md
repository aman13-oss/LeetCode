# 2877. Create a DataFrame from List

**Difficulty:** Easy

## Problem

Create a DataFrame from a 2D list.

You are given a 2D list called `student_data` that contains the grades of some students.

Create a DataFrame from this 2D list with two columns: `student_id` and `age`.

The DataFrame should have the following structure:

- `student_id` as the first column
- `age` as the second column

## Example

### Input
```text
student_data = [
    [1, 15],
    [2, 11],
    [3, 11],
    [4, 20]
]
