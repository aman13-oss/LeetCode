# 2878. Get the Size of a DataFrame

**Difficulty:** Easy

## Problem

Write a solution to calculate the number of rows and columns in a given DataFrame.

You are given a DataFrame named `players`.

Return the size of the DataFrame as an array `[number of rows, number of columns]`.

### Input
```text
players =
+-----------+-------+
| player_id | name  |
+-----------+-------+
| 1         | Alice |

+-----------+-------+
