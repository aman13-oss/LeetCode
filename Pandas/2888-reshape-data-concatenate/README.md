# 2888. Reshape Data: Concatenate

**Difficulty:** Easy

## Problem

Given two DataFrames `df1` and `df2` with the same columns, concatenate them vertically.

Return the resulting DataFrame.

## Example

### Input

```text
df1:
+----+-------+
| id | name  |
+----+-------+
| 1  | Alice |
| 2  | Bob   |
+----+-------+

df2:
+----+-------+
| id | name  |
+----+-------+
| 3  | John  |
| 4  | Mark  |
+----+-------+
