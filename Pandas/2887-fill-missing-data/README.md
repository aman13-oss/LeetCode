# 2887. Fill Missing Data

**Difficulty:** Easy

## Problem

Given a DataFrame `products` with a column `quantity`, replace every missing value in the `quantity` column with `0`.

Return the resulting DataFrame.

## Example

### Input

```text
+------------+----------+
| product_id | quantity |
+------------+----------+
| 1          | 10       |
| 2          | NULL     |
| 3          | 20       |
+------------+----------+
