# 2884. Modify Columns

**Difficulty:** Easy

## Problem

Given a DataFrame `employees` with a column `salary`, modify the `salary` column by doubling every employee's salary.

Return the modified DataFrame.

## Example

### Input

```text
+-------+--------+
| name  | salary |
+-------+--------+
| John  | 5000   |
| Alice | 6000   |
+-------+--------+
