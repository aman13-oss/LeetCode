# 2885. Rename Columns

**Difficulty:** Easy

## Problem

Given a DataFrame `students`, rename the column `id` to `student_id` and the column `name` to `student_name`.

Return the resulting DataFrame.

## Example

### Input

```text
+----+-------+
| id | name  |
+----+-------+
| 1  | Alice |
| 2  | Bob   |
