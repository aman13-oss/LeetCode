# 2881. Create a New Column

**Difficulty:** Easy

## Problem

Given a DataFrame `employees` with the columns `name` and `salary`, create a new column named `bonus`.

The `bonus` should be equal to two times the employee's salary.

Return the resulting DataFrame.

## Example

### Input

```text
+-------+--------+
| name  | salary |
+-------+--------+
| John  | 5000   |
| Alice | 6000   |
+-------+--------+
