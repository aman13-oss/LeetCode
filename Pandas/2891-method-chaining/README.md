# 2891. Method Chaining

**Difficulty:** Easy

## Problem

Given a DataFrame `employees`, use Pandas method chaining to:

1. Filter employees whose salary is greater than 50000.
2. Sort the resulting DataFrame by salary in descending order.
3. Return the resulting DataFrame.

## Example

### Input

```text
+-------+--------+
| name  | salary |
+-------+--------+
| John  | 60000  |
| Alice | 45000  |
| Bob   | 80000  |
+-------+--------+
