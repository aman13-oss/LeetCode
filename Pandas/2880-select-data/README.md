# 2880. Select Data

**Difficulty:** Easy

## Problem

Given a DataFrame `students`, select the rows where:

- `student_id` is equal to 101 or 202.
- Only the `name` and `age` columns should be returned.

Return the resulting DataFrame.

## Example

### Input

```text
+------------+-------+-----+
| student_id | name  | age |
+------------+-------+-----+
| 101        | Alice | 15  |
| 102        | Bob   | 16  |
| 202        | John  | 17  |
+------------+-------+-----+
